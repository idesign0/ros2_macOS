# mimick_vendor (ros2/Mimick @ 4dbd495): builds the Mimick C mocking library. On the
# Xcode 26.6 runner its preprocessor machinery leaves an unbalanced function-like macro
# invocation open, which then swallows the SDK's integer typedefs -> "unexpected token
# in argument list" across sys/_types/_int8_t.h.._uint64_t.h and stdint.h. It is a
# <test_depend> ONLY (rclcpp / rclcpp_lifecycle / rclcpp_action / rcl / rcutils /
# rcl_yaml_param_parser / rosidl_typesupport_c use it solely for tests) and the toolchain
# forces BUILD_TESTING OFF workspace-wide, so nothing builds against it and it cascades to
# nothing — an isolated red. (Builds clean locally on Apple clang 21 with the full CI flag
# set incl. -fexperimental-library + the macos_compat force-include, so the trigger is
# runner-specific and not reproducible here for a targeted patch.) Skip until a reproducer
# exists; zero build impact given tests are off.
mimick_vendor
